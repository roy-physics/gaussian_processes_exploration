# Gaussian Processes Exploration

A short Jupyter notebook exploring Gaussian process regression with scikit-learn. It compares dot-product and RBF kernels on a noisy straight line and an oscillating function, plotting the true functions, predictions, and uncertainty bands.

To run it, install `numpy`, `matplotlib`, and `scikit-learn`. Then open `gaussian_processes_exploration.ipynb` in Jupyter and run the cells in order. 

Feel free to play around, add your own functions, change the hyperparameters, experiment with different kernels, etc. The point is to build intuition!
